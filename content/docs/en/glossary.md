# Glossary

| Term | Meaning |
| --- | --- |
| Canonical asset | A network's native asset or a protocol-canonical route token (e.g. a registered ONEbridge pair). |
| Curated token | Exact network + contract in the {{BRAND}} curated registry. |
| Market listed | Exact contract listed on a market source; not a safety claim. |
| DEX discovered | DEX pair evidence for the exact contract; not a safety claim. |
| Imported · unverified | A token you added by exact address on this device. |
| Coverage class | What {{BRAND}} could check on a network: full index, curated balance scan, known tokens, native only, not checked, failed, pending. |
| Total known value | Sum of priced assets; unpriced assets are counted separately. |
| Common finalized pin | The highest finalized block two independent data sources both serve with the same hash. |
| Operator group | The organisation behind an RPC endpoint; two endpoints of one group are not independent. |
| Runtime drift | A change of pinned contract code, roles, pauses or settings after verification. |
| G5 | The technical verification of the ONEchain → BSC route at pinned blocks ({{G5_STATUS}}). |
| Execution gate | The global switch that keeps sending disabled until the release gates pass (sending: {{SENDING}}). |
| Fail closed | When something cannot be verified, stop instead of continuing. |
| Non-custodial | {{BRAND}} never holds your keys or funds; your wallet signs. |
