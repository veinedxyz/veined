## V1.4 retirement and new sources (2026-10-04)

The paid broad-portfolio adapter above is retired from the application: `OTHERBRIDGE_PORTFOLIO_API_KEY` and `api.covalenthq.com` were removed from the active code path and server host allowlist; a deprecated, transport-less copy exists only in `tests/fixtures/legacy-indexer-provider.ts` for historical binding regression tests. No replacement paid portfolio, indexer or price API was introduced.

RPC providers observe queried public addresses. Terms of individual public RPC endpoints must be reviewed before production traffic.
