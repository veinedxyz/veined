# Otherbridge V1.2 terminology

Financial wording must distinguish amount from fee, custody from spendable reserve, source confirmation from destination delivery, and historical evidence from a current executable quote. A reverted simulation is failure. G5 remains incomplete and real sending disabled in every locale. Proper names, asset symbols, hashes, token/network IDs and API codes remain technical identifiers.

Canonical glossary below is derived from the shipped dictionaries, including the complete reserve warning so the bound is never presented as verified spendable liquidity. New locale terms received semantic review; independent native-speaker certification was not performed.
