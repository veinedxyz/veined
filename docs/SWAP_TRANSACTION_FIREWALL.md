# Swap transaction firewall

V1.15.1 repair candidate: **RETURN_FOR_REPAIR / EXECUTION_CLOSED**. Status is a review gate; independent security/legal approval and production release are external.

EVM review decodes the actual ABI calldata and re-encodes every command/action canonically before comparing the whole transaction with the independently constructed normalized route. Chain, sender, exact router version/address, value, deadline, tokens, amounts, recipient, split shares/allocations, route continuity and aggregate minOut/maxIn are bound. Unknown command bytes, allow-revert flags, arbitrary subplans, embedded permits, hidden payments and nonzero/unreviewed hooks fail closed. The current Uniswap layout includes the 2.1.2 min-hop-price field; Infinity CL/BIN use their own keys/actions/managers. Aerodrome builds safe methods only; Slipstream multicalls permit only reviewed swap/unwrap/refund order.

pools.ts independently resolves classic pools from pinned factories and verifies singleton pool keys/slot0. Current router and singleton manager/state-view bytecode hashes plus EIP-1967 implementation/beacon slots are checked against generated pins. A deployment mismatch returns REVIEW_REQUIRED. Other captured deployment hashes are provenance observations unless the runtime explicitly verifies that role; a captured hash alone is not audited code correspondence.

Solana review accepts canonical unsigned v0 serialization with one payer/signer, actual valid blockhash, independently resolved LUT owner/index/deactivation/digest, exact writable/account roles and reviewed top-level programs. Current on-chain Jupiter IDL is decoded with bounded Borsh and complete byte consumption. Route graph allocations and input/output nodes must agree; the normalized route binds venue, share, pool, token pair and independently parsed Whirlpool pool/vault state. Unknown CPI families cannot gain reviewability from a familiar outer Jupiter program.

Mint/token ownership, decimals, initialization, source/destination ATAs, delegate/freeze/close authorities, exact input, output/slippage, platform/referral fields, compute fee, native transfer/wrap/sync/close ordering and rent are checked. Legacy SPL and Token-2022 have separate size/TLV rules; only reviewed metadata mint extensions and immutable-owner account extension are admitted. Transfer fees, transfer hooks, confidential and unknown economic extensions fail closed. Executable program account digests, loaders and upgradeable ProgramData address/header (deployment slot and authority) are pinned before inspection and rechecked after simulation. ProgramData ELF build/source correspondence is not independently audited.

The canonical review digest binds exact immutable quote ID, intent digest, transaction digest, source block/slot, wallet epoch, recipient/slippage, decoded route, pool/program proof and simulation. Refresh or intent change invalidates old review authority. The API never accepts client transaction bytes or user RPC URLs. No result is signable and no wallet authority is created.
