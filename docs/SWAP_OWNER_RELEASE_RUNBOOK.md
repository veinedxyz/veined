# Future controlled Swap pilot

No real pilot is executed in V1.16. The wallet request/signature/approve/permit/broadcast path remains absent.

Future owner decision must bind the exact RC/build/baseline, provider and API/router revision, chain, owner wallet, recipient and a small explicitly approved amount. Revalidate fresh quote, price/slippage, zero Otherbridge fee, allowance policy, transaction decoding, route/build equality, pool/program identity, simulation digest and expiry. Show transaction review before wallet confirmation. Any wallet/account/chain epoch change invalidates review and build.

Only after separate approval may a future implementation request wallet confirmation, broadcast once, verify receipt/finality and reconcile post-trade balance. A failed provider, stale quote or incomplete simulation is not executable. Preserve incident evidence on mismatch; activate provider/global kills and invalidate release receipt.

Swap and Bridge require different surface receipts. Enabling either cannot enable the other. G7 requires its own owner approval. This runbook is a future procedure, not authorization or a valid receipt.
