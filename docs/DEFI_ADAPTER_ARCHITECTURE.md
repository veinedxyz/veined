# Read-only protocol adapter architecture

V1.14.1 performance hardening (read plans, request budget, cache policy, timing receipts): [report](V1141_DEFI_PERFORMANCE_HARDENING.md) · [performance](DEFI_PERFORMANCE.md) · [request budget](DEFI_REQUEST_BUDGET.md) · [cache policy](DEFI_CACHE_POLICY.md) · [test matrix](V1141_TEST_MATRIX.md).

Versioned deployments/discover/readPosition/getCoverage interface in src/defi/adapters.ts. Registry generated from hash-checked pinned official sources. Minimal local view ABIs in abi.ts. Adapters live server-side; lazy Portfolio UI imports only the schema, economic graph and integer/string display helpers. Its client-only local Suspense boundary prevents chunk loading from suspending the wallet scan and aborting an existing wallet continuation request; the accepted progressive-scan E2E proves this boundary.

DefiReader authorizes exact registry targets and targets obtained from known protocol views/factory validation. Each RPC capability is exact target + encoded view calldata. Existing generic RPC policy continues rejecting unlisted selectors and every transaction/signing method. No browser URL/ABI/oracle input. Pinned same-endpoint block number is used for related balances, debt, risk and conversions; block hash rechecked before publishing. Chain identity and block freshness checked, code hashes observed. Aave provider identity and receipt/debt relationships, LP factory/pool identity and current NFT ownership are validated. Upgrade code hashes are evidence, not a blanket upgrade audit guarantee.

Defaults: 3 concurrent deployments; 6 deployments per app page; 10 s adapter timeout; 15 s page deadline; 256 logical read-call budget; 128 call batch limit; 64 index refs; 100 NFT limit; 20 UI pages maximum. Verified JSON-RPC batching (not unverified Multicall) accelerates Aave reserve reads; fallback fanout is 4 per adapter. One failed adapter returns partial coverage. Three consecutive failures cool a deployment for 60 s. Single-flight and 30 s bounded cache keys include explicit wallet, client scope and page/deployment scope. Wallet results render independently.
