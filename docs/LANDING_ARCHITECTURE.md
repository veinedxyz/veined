# Landing architecture (V1.11)

## Routes

| Path | Owner | Notes |
| --- | --- | --- |
| `/` | `src/app/(marketing)/page.tsx` | public landing (server-rendered) |
| `/docs`, `/docs/<page>` | `src/app/(marketing)/docs/[[...slug]]/page.tsx` | public docs |
| `/bridge` `/swap` `/portfolio` `/activity` `/activity/<id>` `/networks` `/help` `/about` `/settings` | `src/app/(app)/[...path]/page.tsx` + `src/app/(app)/layout.tsx` | the existing application, unchanged behaviour |

Route groups keep the two shells apart: the root `src/app/layout.tsx` only carries the document, i18n and SEO
defaults; the application shell (Privy wallet layer, routing, G7 local pilot gate) lives in `(app)/layout.tsx` and
is never part of `/` or `/docs`. Header: **Launch App** → `/bridge`, **Docs** → `/docs`. Old deep links keep working
(`/bridge` was already the bridge view; the former `/` bridge view moved to `/bridge`, and the in-app brand mark
links to the landing page).

## Content (13 sections)

Hero ("Find where your assets are. Move them across difficult networks. Swap them where you need them."), Find your
assets, Portfolio, Bridge, Swap, Network reach, How it works, Safety / non-custody, Self-hosted data / API, product
visuals (labelled *Illustrative preview* panels inside the sections — no real wallet data), FAQ, Final CTA, Footer.

Every number is computed at render time from committed registries (routing catalog mainnets, chain identities,
asset registry, ONEbridge pairs, fee policy, 24 locales); nothing is hard-coded. Claims policy: no "100 % safe",
"trustless", "audited", "all chains/tokens guaranteed" or "risk-free" (checked by `tests/e2e/v111.spec.ts` and the
docs consistency test). The product status line states that sending is disabled in the public app today.

Visual style: Otherbridge charcoal + sage, per-network ambient light from the existing network themes; no blue AI
gradient, no neon. Strict CSP compatible (no inline styles; marketing CSS is a static stylesheet).

## i18n

Landing strings live in the `landing` namespace of all 24 app locales (`src/i18n/locales/*.json`, checked by
`scripts/i18n-check.mjs`). The locale comes from the same cookie/Accept-Language resolution as the app
(`(marketing)/locale.ts`); the language selector (`marketing-language.tsx`) is the only client component.

## Social links and SEO

- `src/server/site.ts`: X, GitHub, Telegram, Discord (official hosts only, real profile path), docs mirror and status
  page come from `OTHERBRIDGE_SOCIAL_*`, `OTHERBRIDGE_DOCS_URL`, `OTHERBRIDGE_STATUS_URL`. Unset or invalid → the link
  is **hidden** (no `#` placeholders, nothing invented). None is configured in this repository.
- Title/description per locale, OpenGraph + X card (`summary_large_image` with the branded
  `public/og/otherbridge-og.png`, 1200×630, generated by `scripts/og-image.mjs`, no wallet/user data), favicon
  (`src/app/icon.svg`, `apple-icon.png`), `robots.ts`, `sitemap.ts`, canonical URLs.
- Indexing is **opt-in**: `OTHERBRIDGE_PUBLIC_INDEXING=true` **and** an https `OTHERBRIDGE_PUBLIC_ORIGIN`. Otherwise
  `robots` disallows everything, the page is `noindex`, the sitemap is empty, and no canonical/OG URL is emitted (no
  guessed `localhost` URLs).

## Bundle separation

The marketing layout and pages import no Privy, wallet, portfolio client, routing client, firewall, G7 or
transaction module — enforced by an import-graph test (`tests/unit/v111-docs-site.test.ts` "bundle boundary") and by
the E2E network check (no `/api/portfolio|routing|bridge|assets|catalog`, no Privy/WalletConnect requests on `/` or
`/docs`). Budgets (`scripts/bundle-budgets.json`, measured by `scripts/measure-bundle.mjs` on `next start`):
see `V111_PRODUCT_COMPLETION.md` → Performance.
