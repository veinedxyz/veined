# V1.12 asset image coverage

The accepted baseline had 343 chains, 304 real logos (88.6%), 39 monograms; 417 registry assets, 414 logos (99.3%). V1.12 has 343 chains and 339 real logos (98.8%; mainnet 99.4%), with 4 monograms. The registry has 418 assets (75 canonical, 341 curated, 2 market-listed), 417 local logos (99.8%). Source evidence and the remaining inventory are under network-images and token-images in evidence/otherbridge-v1-12/v112-20261007T100941277Z-de7692.

35 missing chain logos use the exact accepted TVL catalogue row (same network/chain ID where present) and exact publisher filename from the [DefiLlama chain icon repository](https://github.com/DefiLlama/icons/tree/v2/assets/chains). Catalogue-only identities keep their accepted catalogue ID; no invented chain ID or environment is assigned. Previously reviewed images are preserved. XIO Ethereum and CROSS BSC images use exact token-contract evidence. Solana USDC uses the issuer's [mainnet mint](https://developers.circle.com/stablecoins/usdc-contract-addresses) plus matching Trust Wallet SPL metadata and mint-specific image. Base58 case is preserved. A logo is attribution, never financial trust or routing permission.

Remaining fallbacks: MTT Network (6880), Strato Chain (catalogue-only), the two synthetic local networks (31337/31338), and ONEchain USDTx at 0x1c37d4f44ed3ec86d96868001cfa89e97112a85c. Failed source attempts and exact identity inventory are retained. No symbol substitution or fabricated logo is used.

All remote acquisition uses exact HTTPS host admission, public DNS pinning, bounded redirects/time/bytes and sanitizer output. Original SVG/HTML/animated/unknown image bytes are rejected; JPEG uses the existing isolated offline rasterizer and canonical re-encode. Browser images are same-origin local sanitized assets or exact hash-addressed asset-image cache paths. Local traversal, protocol-relative URLs, remote URLs and ambiguous paths are refused. Package-lock/dependencies are unchanged.

Portfolio now accepts the shared sanitized image path rules, including case-sensitive Solana mint filenames and exact API image hashes, rather than the old EVM-only filename regex. Expanded rows and attention lists use the same verified display path. Solana metadata remains decimal-bound, exact-mint and trusted-level checked. Swap selected tokens use chain+contract lookup. Native marks use the accepted chain logo. Landing preview images use exact registry identities; figures remain explicitly illustrative. Registry coverage does not mean every possible wallet-held or dynamically discovered asset has a known image.
