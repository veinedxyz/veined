## Identity record

Each record: internal `id`, `chainId`, `caip2`, official `name`, `shortName` (official name without trailing
"mainnet/network/chain", cut at a word boundary, ≤ 16 chars), `environment` + `environmentSource`, `ecosystem`,
`nativeSymbol`, `explorer`, `logo` (same-origin path), `logoSource`, `logoProvenance` (source URL or repository
record + source SHA-256), `logoSha256`, `sources`, `updatedAt`.

Matching is by **exact chain id** only (Trust Wallet via the wallet-core registry chain id; CoinGecko via asset
platform `chain_identifier` or the exact coin id carried by the TVL catalog row). Never by name or symbol.

## Image ingestion (server-side only)

The browser never loads a remote logo. `scripts/assets/sync.ts` downloads through `src/assets/safe-fetch.ts` and
stores sanitized copies under `public/assets/chains/` (content-addressed file names):

- HTTPS only, port 443, exact host allow-lists per job (images: `raw.githubusercontent.com` for Trust Wallet,
  `coin-images.coingecko.com` / `assets.coingecko.com`; runtime import logos additionally `dd.dexscreener.com` /
  `cdn.dexscreener.com`; data: `chainid.network`, `api.coingecko.com`, `api.dexscreener.com`, `li.quest`,
  `bridge-api.crosstoken.io`), public DNS only, the resolved IP is pinned per hop (SSRF / DNS rebinding), ≤ 3
  redirects re-checked hop by hop, byte cap (600 kB for logos), timeout.
- `src/assets/image-sanitize.ts`: MIME sniffing by magic bytes (the server `Content-Type` is ignored), HTML and
  SVG rejected (SVG is never accepted from remote sources), GIF/unknown rejected, PNG fully decoded (CRC checked,
  chunk policy, bounded inflate — decompression bomb guard — dimension cap) and **re-encoded** without metadata
  chunks; WebP container validated and rebuilt without EXIF/XMP; CoinGecko JPEGs are rasterized to PNG in an offline
  sandboxed Chromium during sync only (never at request time). Output ≤ 64 px, SHA-256 recorded.
- `pnpm assets:verify` re-sanitizes every committed image and fails on any byte difference.

Raw upstream snapshots and per-request evidence: `evidence/otherbridge-v1-11/<run>/asset-sync/`.
