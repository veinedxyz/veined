# Multichain security boundary

SDK/API only in the server adapter; integrator Otherbridge, providers empty, chain preload/version probe disabled. HTTPS public `li.quest/v1` and an allowlist of six GET read paths: chains/tools/connections/tokens/quote/status. The user cannot supply a URL/header/API key. All DNS results must be public IPs; the HTTPS request is pinned to that verified IP via lookup. There is redirect/non-JSON rejection, a 10-second deadline, a 4 MB response limit, abort and runtime schemas. Large chain ID JSON numbers are preserved as strings before parsing.

Same-origin loopback host/origin check; 16 KB request body and strict action schema. In-process limits of 90 read requests/minute and 60 quotes/2 hours. 429 fail closed. For a metadata 5xx, a single safe read retry after 250 ms; no quote retry/poll. The public catalog/token cache contains no accounts; account-bound quote responses are no-store and are not written to the shared cache. Error responses are enums; wallet session/upstream credential/raw transaction payload are not carried to the client or the general log. Public research probes record sanitized request/hash/provenance only with public fixture addresses.

The logo transport applies a separate HTTPS origin/path allowlist, size/deadline/content type limits, XML parsing and rejection of script/handler/doctype/entity/foreignObject/external href/image/CSS URL. The browser loads only same-origin local assets. An unknown asset uses the geometric fallback. The existing nonce CSP and nosniff are preserved; there is no remote SVG execution path.

`executionGate` frozen enabled=false; sign/approve/broadcast/deploy null. The execution call interface throws WRITE_DISABLED. The server recognizes no write action. A malicious OTHERBRIDGE_MODE=local-test or enable-mainnet=true cannot open the production gate. The static safety scanner searches the routing layer and components for wallet sign/approve/send, executeRoute/executeStep/resumeRoute and browser SDK import; the absence of provider dependency/init is also checked. The original ONE local-test writer namespace is only a synthetic isolated test provider; the real ONE registry writer remains null.

ONEbridge G5 BLOCKED is maintained: the deployment source Standard JSON/build/runtime equivalence and the spendable reserve semantics are not complete. The new API quote/catalog is not evidence of this. M11 NOT_RUN — USER_APPROVAL_REQUIRED; M12 BLOCKED — RELEASE_APPROVAL_REQUIRED. Because of the user boundary, this milestone does not attempt to open them. There is no key, real signature, approve, broadcast, deploy, V2 gas or V3 standalone swap.

Raw diagnostic errors and old checkpoints are not deleted. The review ZIP performs redaction only in the copy; the real .env, caches, wallet sessions, trace ZIP, dependency tree and .git are not included. The SHA inventory shows the source/checkpoint relationship; old evidence is not presented as a new test run.
