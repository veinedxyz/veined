# Dynamic network and logo catalog

In the 3 October 2026 reads, the current route data yielded 76 networks + explicit ONEchain = 77 entries. This number is not a support list; each server catalog read normalizes the current chain/tool data. EVM/SVM/UTXO/MVM/TVM/STL and API testnet entries are visible. Testnet bridge quotes are closed in this milestone. ONEchain 612055 is always a custom provider; the existing ONE→BSC acceptance form and the G5 boundary are preserved. Other ONE pairs/reverse/composition are NOT_EXECUTABLE.

A network being visible does not mean that there is a bridge connection or a real quote. Connection metadata is theoretical. If there is no real quote, 'No executable route' is shown. If the public data is cut off, the snapshot appears stale; quote/review is closed. Native asset metadata and token addresses come from upstream; no token is fabricated from a name, and no VM or wallet address from an ID. Large chain IDs are preserved as full strings.

Sources: `catalog-snapshot.json` (stale fallback), `generated-assets.json` (managed visual map), `public/networks/catalog/` (76 hash-named local SVGs), `public/networks/neutral.svg` (geometric fallback with text for a new, unreviewed asset). The current API list is independent of the snapshot. All entries whose logos have been reviewed use their own real icon; a new unknown icon is not made to imitate a brand.

`pnpm networks:sync`: first choose a unique `OTHERBRIDGE_EVIDENCE_ROOT`. It reads the current chain metadata; it applies a public-chain-asset-URL-only allowlist, HTTPS, deadline/byte/MIME limits and SVG security parsing. It creates files under new content-hashed names with `wx`; it checks the hash of an existing file. It does not delete assets, does not change the ONE/BNB icon, and does not commit/deploy. The manifest diff/source/SHA-256/provenance records can be reviewed. An arbitrary logoURI from the API is not passed to the browser.

Each network: logo/primary/accent/glow/badgeDark/badgeLight/logoSurface/provenance tokens. 3-digit SVG hex palettes are normalized. Black/white official logos get a matte contrast plate; the logo is not recolored. Glow is derived from the SVG palette and is not an official brand color claim. The ONE/BNB tokens are preserved with their earlier official source notes. Charcoal center, low-intensity ambient light at the source and destination; network color is not an information channel in place of text.

Latest source/diff: `evidence/otherbridge-v1-1/multichain-20261002T203410Z-146be9/asset-sync-b/asset-sync.json`. It lists future networks in the registry automatically; a new asset is added after a safe sync/review. The enum VM classes are not a hardcoded list of supported networks.
