# Swap incident runbook

V1.15.1 repair candidate: **RETURN_FOR_REPAIR / EXECUTION_CLOSED**. Status is a review gate; independent security/legal approval and production release are external.

Immediate containment: set SWAP_DISABLED_PROVIDERS to comma-separated exact mode names: UNISWAP, UNISWAPX, PANCAKESWAP_SMART, PANCAKESWAP_X_INTENT, AERODROME_CLASSIC, AERODROME_SLIPSTREAM, JUPITER_META, JUPITER_ROUTER, TITAN. A group kill lists each mode. Set SWAP_BUILD_ENABLED=false to stop unsigned builds and SWAP_REVIEW_ENABLED=false to stop review. SWAP_EXECUTION_ENABLED=true is rejected; execution has no enable branch. Restart workers to clear quote/review references and cancel streams. Confirm killed modes receive no query and unaffected modes continue.

| Incident | Evidence and repair before quote/review restoration |
|---|---|
| Universal Router migration or Infinity router/manager drift | Preserve chain/block/address/code hash and EIP-1967 slots; compare official deployment revision and command/actions; review new pins, add decoder mutations and repeat real pinned-fork simulation. Never auto-activate a future address. |
| Compromised provider / malicious route discrepancy | Capture sanitized code, time and quote/transaction digest; close that mode and review; reproduce with anonymized fixture; compare normalized route against actual decode and independent pools/deltas; rotate only server credentials through the operator secret store. |
| Simulation-wide failure | Close review; check RPC chain/context/schema/support and program/router pins; distinguish outage, unfunded account, stale quote and semantic failure. Restore only after exact transaction economic replay passes. |
| Dependency advisory | Separate root frozen graph, effective production graph and dev-only compatibility graph; retain raw audit; trace introducer, patch via reviewed compatible isolated dependency/alias; run frozen install, parser/runtime regressions, SBOM/license and build tracing. HIGH has no self-approved exception. |
| Solana program upgrade | Close affected family; compare loader/program/ProgramData header and current IDL/account layouts at independent RPC; source-review change, regenerate reviewed pins/fixtures and repeat unsigned economic simulation. A familiar program ID is insufficient. |
| Titan stream protocol drift | Close stream; keep raw frames out of logs; retain schema error code/frame length only; verify official protocol/version/subprotocol; add bounds/auth-redaction/reconnect/cancel fixtures before update. Unknown compression/text frames remain closed. |
| Jupiter API generation change | Close hosted build mode; compare current official Swap API and on-chain IDL; add current order/build/routePlan/account fixtures and economic mutations. Never silently switch to legacy V1. |

Observability: Node 24 built-in SQLite stores strict anonymous hourly mode/chain/phase aggregates at SWAP_HEALTH_PATH (default .otherbridge/swap-health/health.sqlite). Retention is 48 hours with at most 49 hourly buckets and bounded enum dimensions (at most 5292 rows); WAL size target 1 MiB and automatic checkpoints. Latency buckets are <=100/500/1000/2500/5000 ms and above. Counters separate timeout, rate limit, schema/firewall/simulation failure and cooldown. No wallet, token, amount, URL, error body, request ID or credential labels. Persistence errors increment swap_health_persistence_failure_total. Mount a writable durable local volume and monitor disk/SQLite failure; this is per-host durability, not a distributed limiter. Export only anonymous aggregates via the existing internal metrics surface.

Configuration: UNISWAP_API_KEY and JUPITER_API_KEY are server-only; TITAN_WS_ENDPOINT must be the reviewed exact uncompressed wss endpoint, and TITAN_AUTH_TOKEN stays in the Authorization boundary. PCSX_QUOTE_ENABLED controls opt-in, not proof that anonymous quote API requires authentication. Timeouts/concurrency/cooldown/router/program rules are bounded in source. No NEXT_PUBLIC secret. Do not log payloads, auth headers or URL credentials. Rotate upstream access outside this package and repeat source/log/browser scans.

Origin readiness: owner-controlled HTTPS domain, exact OTHERBRIDGE_APP_ORIGINS, Privy origin registration, provider API key origin/egress/quota policy, server HTTPS/WSS allowlist, trusted proxy/rate-limit ingress, CSP, no wildcard credentialed CORS, secure cookies, internal metrics access, incident owner and independent legal/security release references. DNS, deployment and execution are unchanged by this checklist. See DOMAIN_RELEASE_CHECKLIST.md.
